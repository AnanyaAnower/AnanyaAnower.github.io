Design and Development of an In-sole Foot Pressure Sensor System for Gait Analysis →

Biomedical Instrumentation | Clinical Research

  • Designed a low-cost, wearable in-sole system using five Force-Sensitive Resistors (FSR) to monitor plantar pressure distribution.
  • Developed a data acquisition framework using an Arduino UNO to transmit sensor data for real-time visualization.
  • Analyzed 2D heat maps generated via Python to identify significant variations in foot pressure between healthy subjects and those with gait abnormalities.
  • Diagnosed specific troublesome regions in patients with Poliomyelitis and Diabetic Foot by mapping pressure intensity to color-coded spatial clusters.
